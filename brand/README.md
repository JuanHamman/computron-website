# Computron Tech brand

Design source: Claude Design canvas "Computron Tech Brand" (logo, palette, type, signature, hero).

## Logo

The mark is a C-shaped toggle track with a knob. Off: knob inside on the left, grey track. On: knob docked in the
gap on the right, Signal-blue track. **The logo is always the On state**; Off exists for the animation only.
The mark doubles as the capital C, so the wordmark is mark + "omputron" in Space Grotesk Bold.

- Component: `src/components/Logo.tsx` (`Logo` lockup, `LogoMark` alone, `animate` plays off → on once).
- Favicon / app icon: tile version in `src/app/icon.svg`, `src/app/favicon.ico`, `src/app/apple-icon.png`.
- Raster mark for email and documents: `public/brand/mark-96.png`, `public/brand/mark-512.png`.
- Social preview: generated by `src/app/opengraph-image.tsx`.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#0A0E1A` | Page ground |
| Navy | `#121A2E` | Cards, scrolled nav |
| Steel | `#1E2A45` | Borders |
| Signal 500 | `#2E6BF0` | Buttons, fills, logo track (white text 5.0:1) |
| Signal 300 | `#7DA6FF` | Links, labels, icons on dark (8.1:1 on Ink) |
| Signal 600 | `#1F55D1` | Hover fills; links on light |
| Mist | `#A9B4C8` | Body text on dark |
| Muted | `#8A96AD` | Captions on dark (6.3:1) |
| Paper / Fog | `#FFFFFF` / `#F4F5F8` | Email and document grounds |
| Graphite | `#525E75` | Secondary text on light |
| Teal | `#2DD4BF` | Doppelgone only |

Tailwind names are mapped to these in `src/app/globals.css` (`blue-500` = Signal 500, `blue-400` = Signal 300, etc.).

## Type

Space Grotesk 600/700 for headings and numeric highlights (`font-display`), Inter for everything else.
Body never below 16 px on the site.

## Email signature

`brand/email-signature.html`: open in a browser, copy, paste into Gmail / Outlook / Apple Mail signature settings.
